Интерактивный процедурный генератор динамических проводов, кабелей и эффектов передачи данных (MoGraph) для **Maxon Cinema 4D (2024 / 2025 / 2026)**.

---

## 🌟 Ключевые возможности

* **Многоточечная маршрутизация ($N \ge 2$ точек):**  
  Прокладывайте кабель через 2, 3, 5 или любое количество объектов / Null. Скрипт рассчитывает непрерывную гладкую цепную линию с индивидуальным провисанием между каждой парой соседних точек.
* **Интерактивный список `InExclude` в User Data:**  
  Добавляйте, удаляйте, меняйте порядок опорных точек прямо в окне **Attribute Manager** перетаскиванием мышью. Можно временно отключать отдельные опоры кликом по чекбоксу.
* **Реальное время (Viewport 60+ FPS):**  
  Двойной солвер (`Wire_Master_Solver` + `Wire_Sweep_Solver`) с флагом `TPYTHON_FRAME = False` мгновенно пересчитывает форму кабеля при перетаскивании ползунков или перемещении целевых объектов в пространстве без необходимости запускать воспроизведение таймлайна.
* **Эффект передачи данных (бегущие сферы MoGraph):**  
  * Движение в обоих направлениях: **А ➔ Б** и **Б ➔ А**.
  * Поддержка до 4+ независимых каналов данных.
  * Интерактивная регулировка размера сфер, скорости (%/сек), шага/дистанции (см) и фазового смещения (%).
  * Режим **Render Instance** обеспечивает сверхбыструю отрисовку во вьюпорте и моментальный отклик на смену размера сфер.
  * Автоматическое создание светящихся неоновых материалов (`Luminance`).
* **Единый центр управления:**  
  **ВСЕ** параметры кабеля и сфер собраны на самом верхнем корневом объекте `Wire_Rig` — больше не нужно раскрывать иерархию в Object Manager.
* **Встроенная система пресетов:**  
  Быстрый выбор стилей (Стандартный, Оптоволокно, Тяжелый кабель, Киберпанк-магистраль, Натянутый провод), сохранение собственных пресетов на диск JSON и применение к выделенному проводу в 1 клик.
* **Скрипт обновления существующих ригов:**  
  `Update_Existing_Cables.py` в 1 клик модернизирует старые провода в открытой сцене до актуального солвера.

## 📥 Установка

1. Скачайте файлы репозитория:
   * `Cable_Generator.py`
   * `Update_Existing_Cables.py`
   * `cable_presets.json`
2. Скопируйте их в папку пользовательских скриптов Cinema 4D:
   * **Windows:**
     ```
     %APPDATA%\Maxon\Maxon Cinema 4D 2026_<ID>\library\scripts\
     ```
   * **macOS:**
     ```
     ~/Library/Preferences/Maxon/Maxon Cinema 4D 2026_<ID>/library/scripts/
     ```
3. Перезапустите Cinema 4D или нажмите **Shift + F11** (Script Manager) -> **File** -> **Reload Scripts**.
4. Скрипт доступен в верхнем меню Cinema 4D:
   **Extensions (Расширения)** ➔ **User Scripts (Пользовательские скрипты)** ➔ **`Cable_Generator`**.

## 🚀 Руководство пользователя (Пошаговый гид)

### Шаг 1. Создание нового провода
1. Выделите в сцене **2 или более объектов / Null** (опорные точки кабеля) с зажатой клавишей `Shift` или `Ctrl`. Порядок выделения определяет порядок прокладки провода.
2. Откройте диалог **`Cable_Generator`** из меню скриптов.
3. В поле **«Выбор объектов в сцене»** отобразится статус, например:
   ```
   🟢 Готово (3 точки): [Null.1] ➔ [Null.2] ➔ [Null.3]
   ```
4. Выберите готовый пресет из выпадающего списка или настройте параметры вручную.
5. Нажмите большую кнопку **«⚡ Создать кабель / провод»**.

---

### Шаг 2. Управление параметрами через User Data
После создания провод автоматически выделится в Object Manager. Перейдите во вкладку **User Data (Данные пользователя)** корневого объекта `Wire_Rig`:

| Параметр | Тип | Описание |
| :--- | :--- | :--- |
| **Опорные объекты (Точки кабеля)** | InExclude List | Список объектов, через которые проходит провод. Можно перетаскивать новые объекты, менять порядок, временно выключать точки. |
| **Толщина кабеля (см)** | Slider | Внешний радиус провода. Меняется плавно во вьюпорте в реальном времени. |
| **Провисание кабеля (см)** | Slider | Величина изгиба цепной линии (может быть положительной или отрицательной). |
| **Направление изгиба (Ось)** | Dropdown | Вектор провисания: `Гравитация (-Y)`, `Вверх (+Y)`, `Перпендикулярно (Авто)`, `Горизонталь X`, `Горизонталь Z`. |
| **Сегментов сплайна (на пролет)** | Integer | Плотность разбиения адаптивного сплайна на каждый сегмент между опорами. |

---

### Шаг 3. Настройка потоков данных (Бегущих сфер)
В User Data на объекте `Wire_Rig` для каждого активного потока создана отдельная вкладка:

* **Поток 1: Включить** — показать / скрыть частицы потока.
* **Размер сфер (см)** — интерактивный радиус светящихся сфер MoGraph.
* **Скорость (%/сек)** — положительное значение направляет поток **А ➔ Б**, отрицательное — **Б ➔ А**.
* **Дистанция (см)** — шаг между сферами вдоль провода.
* **Смещение (%)** — фазовый сдвиг потока вдоль кабеля.

---

### Шаг 4. Добавление дополнительных каналов
Если вам требуется добавить еще один поток (например, третий разноскоростной импульс):
1. Выделите существующий провод `Wire_Rig` в Object Manager.
2. В окне генератора нажмите кнопку **«➕ Добавить поток»**.
3. На риге автоматически появится новый Cloner с уникальным неоновым материалом и новая группа параметров в User Data.

---

### Шаг 5. Пресеты
* **Сохранение:** настройте желаемые параметры в диалоге, введите название в поле ввода и нажмите **«💾 Сохранить»**. Пресет запишется в `cable_presets.json`.
* **Применение к выделенному проводу:** выделите `Wire_Rig` в сцене, выберите нужный пресет в диалоге и нажмите **«📋 Применить пресет»**.

---

### Шаг 6. Обновление старых ригов
Если вы открыли сцену со старыми кабелями:
* Нажмите кнопку **«🔄 Обновить тег»** в диалоге генератора при выделенном проводе, либо
* Запустите скрипт **`Update_Existing_Cables.py`** из меню скриптов — он найдет и обновит все провода в сцене разом.

## 🏗️ Архитектура рига

Создаваемый риг имеет четкую неразрушающую иерархию:

```text
Wire_Rig [Null + Wire_Master_Solver Tag + User Data]
│
├── Wire [Sweep Generator + Wire_Sweep_Solver Tag]
│   ├── Wire_Profile [Circle Spline]
│   └── Wire_Path [Adaptive B-Spline, N-Segments]
│
└── Data_Streams [Null]
    ├── Stream_1_Forward [MoGraph Cloner (Render Instance)]
    │   └── Stream_1_Forward_Sphere [Sphere Primitive]
    └── Stream_2_Return [MoGraph Cloner (Render Instance)]
        └── Stream_2_Return_Sphere [Sphere Primitive]
```

### Технические решения:
1. **Двойной Expression-солвер:** тег `Wire_Master_Solver` на верхнем Null считывает пользовательские параметры и вычисляет координаты сплайна, а тег-компаньон `Wire_Sweep_Solver` на генераторе Sweep инвалидирует кэш генератора, гарантируя 60 FPS перерисовку во вьюпорте при перемещении объектов.
2. **MoGraph Render Instance:** клонеры используют `c4d.MGCLONER_VOLUMEINSTANCES_MODE_RENDERINSTANCE`, что разблокирует интерактивное изменение формы сферы без повторного запекания GPU-буферов Multi-Instance.
3. **DAG Matrix Tracking:** солвер отслеживает матрицу каждого объекта через `t.GetDirty(c4d.DIRTYFLAGS_MATRIX)`, благодаря чему кабель физически следует за перемещаемыми опорами в реальном времени.
